◆ try_decode_pending()

auto LibFlute::File::try_decode_pending ( )

End-of-transmission decode trigger.

The FLUTE layer calls this when it determines the file's transmission has ended (e.g. the FDT no longer lists this file's TOI). For FEC schemes that defer the decode pass — Raptor in particular — this is the cue to actually run TryDecode once per source block. For CompactNoCode the call is a no-op (the per-symbol path already flagged the source blocks complete as data arrived).

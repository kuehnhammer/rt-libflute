Calculate the md5 message digest.

Parameters
inputbyte array whose md5 message digest shall be calculated
lengthsize of the input array
resultbuffer to store the output of the md5 calculation. Make sure it is EVP_MAX_MD_SIZE bytes large
Returns
length of the calculated md5 sum (should be 16 bytes for md5), or a negative sentinel on invalid input. Return type is int (signed) so that if (calculate_md5(...) < 0) evaluates as intended at every call site.
